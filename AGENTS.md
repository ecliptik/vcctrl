# Working in this repository

See [CONTRIBUTING.md](./CONTRIBUTING.md) for this repo's own conventions:
where planning drafts and measurements go, what stays untracked and real,
the guards a commit needs to pass, and what a commit message should say.

This file (and the identical [AGENTS.md](./AGENTS.md)) exists as a pointer
for whichever coding agent is reading a project-instructions file by
convention — the content lives in one place so it can't drift into two.
